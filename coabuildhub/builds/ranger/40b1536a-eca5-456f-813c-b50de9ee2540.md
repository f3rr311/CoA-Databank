Basic leveling Support/Dps Build and maybe viable at  60 but will need to test first as I get to 60 soon.
Spec focus on providing buffs for the party in dungeons and some aoe Dps with the help of the Falcons + Dragon Hawks and Emerald Arrow for some OT AoE damage.
Also I been using it for leveling and everything is going smooth so far!
And in pvp doing good too.

If there is any advice to update let me know and I will look into it. 
PS: First time ever making a build so bear with me. 😅

[rotation]
While leveling don't forget to use [Elude] aka stealth to gain the 10 seconds damage increase buff.

While in [Elude] mode I usually open with Toxic Dart for the DoT and gaining the 10sec dmg increase then Serrated Shot and then it depends on the situation im in but its very easy to learn what to use.

[stats]
For leveling:

Top main priority will be:
>Agility 

And if found gears with 
>Attack Power
>Hit rating 

Also keep an eye for Worldforged gears they're real good upgrades with nice stats !

[leveling]
While leveling solo or in group always keep on mind 
Weapon Enchantments like poisons and burn is very important for more damage depending on which Quiver you're using, 
So if we use Poison Quiver we go with [Nerve Venow] 
And if we use Searing Quiver we go with [Burning Toxin]

What I usually do is keep one of each on my weapons so I can rotate between quivers as I see needed.
