[overview]
my first language is not English, so if there are spelling mistakes I'm sorry, it is a basic guide to understand a little how I play tinker heal in dungeons and if I can help people with this guide then perfect, that is the intention.

[rotation]
Reconstruction and Swarm Nanobots all the time active on tank. 
Recharger Nanobot all the time active on yourself.
When enter in a pull use Replenishment and Shield beacon with the tank and after 4 secons use Overcharge, that is going to returnt to you the used mana. If in that pull is a lot of debuffs use Restorative beacon to to heal passively.
Combat Symbiosis you can use all the time in the guy with the most dps, or you can use in bosses on the pet, because with his casts do a lot of dmg and healing.
Try to use Zap! all the time in tank and yourself because because you two are going to have a nanobots and Zap! is garanteed critical with allies nanobots and that is going to creat a gas to heal 15% of the healing of Zap! in every allies within 8yards.
Try to use Macro-Gravity Zone in a big pulls, and Noise Box in a big pull with a lot of casters.
Medpack Can be used like dispell, or like a 5 target dot healing. 
And Air Strike and Deathball are just abilities to use in a big pulls when people are safe.

[stats]
Im playing more like Spell Power>Crit>Hast.
The principal healing abilities are nanobots, beacons, pet, and Zap! (instant healing abilitie), so you dont need to cast too much, so i prefer more crit than hast. But that doesn't mean you don't have to carry hast. The "useless" stat is spirit, We have 3 powerfull buffs to restore mana, Mana Module, Replenishment Beacon and Nanobot Recharger.

[leveling]
To do quests use Mechano-Bear if you are alone, use nanobots in it and just do damage.

[macros]
My principal macro por petattack is with dmg abilities like bomb or autoattack:

#showtooltip
/use Sticky Bomb
/petattack

And the other macro is for healing pet (ZIGGI-6K) he has a rescue abiltie, and i use normally on me so i just use this macro:

#showtooltip
/use Minicopter-Z

[tips]
When you start learning the class use Stim Augmentation to heal to the party, when you doing heroic and mytic dungeon, you will start using Explosive Augmentation in some pulls and Stim Augmentation in other.
